# Лабораторная работа №5 — Первичная настройка Zabbix

## 🎯 Цель работы

Развернуть систему мониторинга **Zabbix** в виртуальной среде: поднять две виртуальные машины (сервер Zabbix и пользовательский АРМ), добавить оба хоста в веб-интерфейс Zabbix и задокументировать весь процесс.

---

## 📋 Задание

### 1. Подготовка виртуальной инфраструктуры

Развернуть **две виртуальные машины в VirtualBox**:

| Роль | Назначение |
|------|-----------|
| **Zabbix Server** | Сервер мониторинга (БД + веб-интерфейс + сервер) |
| **User Workstation (АРМ)** | Наблюдаемый хост (Zabbix Agent) |

- Сетевой интерфейс каждой VM настроить в режиме **NAT** либо **Bridge** (на выбор).
- Обе VM должны «видеть» друг друга по IP (проверить `ping`).
- Зафиксировать в отчёте: версию VirtualBox, выбранный режим сети, ОС каждой VM, IP-адреса, имена хостов.

### 2. Установка Zabbix Server

Установить **Zabbix** (сервер + frontend + БД) на первой VM, **строго следуя видео-плейлисту** из раздела «Источники»:
- Установить и настроить СУБД, веб-сервер и PHP-зависимости.
- Настроить базу данных и конфигурационные файлы.
- Запустить сервисы `zabbix-server`, `zabbix-agent`, веб-сервер.
- Проверить доступность веб-интерфейса по `http://<IP-сервера>/zabbix`.

### 3. Установка Zabbix Agent на АРМ

На второй VM:
- Установить **Zabbix Agent**.
- Настроить `/etc/zabbix/zabbix_agentd.conf` (`Server`, `ServerActive`, `Hostname`).
- Запустить агент и включить в автозагрузку, проверить порт `10050`.

### 4. Добавление хостов в веб-интерфейсе Zabbix

В веб-интерфейсе Zabbix:
- Добавить **хост Zabbix Server** (интерфейс Agent, шаблон **Linux by Zabbix agent**).
- Добавить **хост АРМ** (интерфейс Agent на IP АРМ, шаблон **Linux by Zabbix agent**).
- Убедиться, что оба хоста в статусе **доступен** (индикатор зелёный) и по ним собираются **Latest data**.

### 5. Документирование

- Схема стенда: версия VirtualBox, режим сети, VM, IP-адреса, роли (таблица).
- Пошаговое описание установки обеих VM и Zabbix: команды, конфиги, скриншоты ключевых этапов — **с опорой на видео-плейлист** (указывайте, какой шаг из какого видео/таймкода взят).
- Возникшие ошибки/сложности и способы их решения.
- Скриншоты: веб-логин, Hosts (оба хоста зелёные), Latest data по обоим хостам.
- Выводы: что удалось, что вызвало трудности, чем этот опыт полезен для дальнейших лаб.
