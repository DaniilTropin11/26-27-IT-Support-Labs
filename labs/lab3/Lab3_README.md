### Задание 2. Диагностика накопителя (HDD/SSD)

1. **Выбор диагностического ПО:**  
   Основной рекомендуемый инструмент — **CrystalDiskInfo**.  
   В качестве аналогов допускается использование следующих утилит:
   - **Для Windows (сторонние диагностические утилиты):**
     - *Victoria (Victoria HDD/SSD)* — профессиональный анализ SMART и тест поверхности;
     - *Hard Disk Sentinel (HDSentinel)* — расчёт процентов «здоровья» и прогноза срока службы;
     - *HD Tune / HD Tune Pro* — считывание SMART и поиск ошибок чтения;
     - *AIDA64* или *HWiNFO64* — разделы «Хранение данных» / «SMART».
   - **Для Windows (фирменное ПО от производителей SSD):**
     - *Samsung Magician* (для накопителей Samsung);
     - *Kingston SSD Manager* (для накопителей Kingston);
     - *Western Digital Dashboard (WD Dashboard / SanDisk)*;
     - *Crucial Storage Executive* (для накопителей Crucial/Micron).
   - **Для ОС Linux:**
     - `smartctl` из пакета *smartmontools* (консольный вывод команды `sudo smartctl -a /dev/sdX` или `/dev/nvmeXn1`);
     - *GSmartControl* (графический интерфейс для smartctl);
     - Утилита *«Диски» (GNOME Disks)* — пункт «Данные SMART и самопроверка».
   - **Для macOS:**
     - *DriveDx*;
     - *smartmontools* (через Homebrew: `brew install smartmontools`).

2. **Сбор данных:**
   - Запустить выбранную утилиту и снять показатели SMART своего накопителя (HDD или SSD).

3. **Требования к фиксации в отчёте:**
   - Скриншот окна программы (или терминала) с отображением SMART-атрибутов и технического состояния;
   - Вывод о состоянии диска (общее техсостояние, температура, наработка в часах);
   - Вывод о ресурсе диска (износ/запас прочности, процент здоровья, наличие ошибок или переназначенных секторов).
