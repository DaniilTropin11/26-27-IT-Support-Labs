# Лабораторная работа №1 

## Тема: Подбор комплектующих и сборка конфигураций ПК

Варианты распределяются по последней цифре номера шифра студента.

---

## ## Задание

В рамках лабораторной работы необходимо **подобрать комплектующие и собрать конфигурации ПК**:

1. **Варианты 1, 2, 3 - Офисный ПК** — для документов, браузера, базового ПО и лёгких облачных сервисов.
2. **Варианты 4, 5, 6 - Геймерский ПК среднего уровня** — для современных игр, VR и обработки видео среднего уровня.
3. **Варианты 7, 8, 9, 0 - Рабочая станция** — для 3D-рендеринга, машинного обучения и работы с большими базами данных.

Для каждой конфигурации необходимо:

- подобрать все комплектующие (процессор, материнская плата, ОЗУ, накопитель, видеокарта (при необходимости), блок питания, корпус, охлаждение);
- подобрать периферийные устройства (монитор, клавиатура, мышь, принтер/МФУ — по заданию);
- указать характеристики и цену каждого устройства (актуальные на 2026 год);
- приложить скриншоты поиска комплектующих на крупных интернет-магазинах (DNS, Ситилинк, ComputerUniverse и др.);
- дать сравнительную таблицу и вывод по «цена/производительность» для конфигурации.

## ## Требования к конфигурациям

# ### Варианты 1, 2, 3 

- Процессор: **Intel Core Ultra 5 (200-я серия)** или **AMD Ryzen 5 (9000-я серия)**.
- Монитор: IPS, диагональ 23–27ʺ, разрешение не ниже FullHD, частота обновления не менее 100 Гц, Flicker-Free, Low Blue Light.
- Материнская плата: минимум 2 порта USB 3.2 Gen2, видеовыход HDMI 2.1 или DisplayPort 1.4, поддержка M.2 NVMe (PCIe 4.0/5.0).
- Дополнительно: предусмотреть возможность расширения ещё 2 портами USB-C через внешние адаптеры.

# ### Варианты 4, 5, 6

- Видеокарта: **NVIDIA RTX 5060** или **AMD Radeon RX 9060**.
- Материнская плата: не менее 2 слотов PCIe 5.0, минимум 4 разъёма SATA и 2 разъёма M.2, сетевой интерфейс 2.5 GbE.
- Принтер: поддержка Wi-Fi, печать с мобильных устройств, месячный объём до 7000 страниц.
- Дополнительно: предусмотреть подключение через контроллер Thunderbolt 4 или USB4.

# ### Варианты 7, 8, 9, 0

- Процессор: **AMD Threadripper 9000-й серии** или **Intel Xeon Scalable 6-го поколения**.
- ОЗУ: ≥ 64 ГБ.
- Видеокарта: уровня **RTX 5080**.
- Материнская плата: поддержка ECC-памяти, сетевой интерфейс 10 GbE, минимум 3 NVMe SSD через PCIe 5.0.
- МФУ: сканер + принтер + копир, сетевое подключение, месячный объём до 30 000 страниц.
- Дополнительно: предусмотреть внешний контроллер для U.2 или NVMe RAID.

## ## Моделирование неисправностей (для конфигураций)

1. **Варианты 1, 2, 3 - Офисный ПК:** смоделировать поломку SSD — подобрать замену с равными или лучшими характеристиками.
2. **Варианты 4, 5, 6 - Геймерский ПК:** смоделировать выход из строя видеокарты — найти альтернативу того же класса.
3. **Варианты 7, 8, 9, 0 - Рабочая станция:** смоделировать выход из строя оперативной памяти — подобрать аналог или лучше (с учётом ECC).
